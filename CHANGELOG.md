# Changelog

## 0.1.0 (2026-11-07)
First public release.
- Chat commands with TAB completion: /help, /seed, /time, /weather, /gamemode, /gamerule, /give, /tp, homes,
  /back, /spawn, /top, /heal, /kill, /flyspeed.
- Cheats switch on Create World and in the game menu; survival, creative and spectator modes.
- Per-world game rules and a settings screen (Options > Beta Essentials...).
- Player skins and capes load again.
- Command API for other mods (`beta-essentials:commands` entrypoint).
